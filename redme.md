# Oumra Prestige 

Bienvenue sur le projet Oumra Prestige, un site web moderne, élégant et professionnel conçu pour une agence de voyage spécialisée dans l’organisation de voyages spirituels (Oumra) vers La Mecque.

Le projet met en avant une expérience utilisateur fluide avec un design minimaliste inspiré des couleurs dorées, blanches, beiges et vertes, symbolisant le luxe, la sérénité et la spiritualité.


## Aperçu du Projet

Oumra Prestige est une plateforme responsive permettant de présenter les services de l’agence, les offres de voyage, ainsi que les informations essentielles pour accompagner les futurs pèlerins.

Le site a été pensé pour offrir :

- Une navigation simple et intuitive
- Une compatibilité sur tous les appareils
- Un design moderne et élégant
- Une interface immersive et professionnelle


## Fonctionnalités

### Design Responsive

- Adaptation automatique aux :
  - Mobiles
  - Tablettes
  - Ordinateurs
- Utilisation d’un système de grille (Grid System)

### Interface Moderne

- Palette de couleurs élégante :
  - Or
  - Blanc
  - Beige
  - Vert
- Typographie propre et lisible
- Sections harmonieuses et aérées

### Interactivité

- Effets hover sur les boutons et liens
- Animations douces 
- Menu mobile interactif
- Transitions fluides


## Technologies Utilisées

- HTML5
- CSS3
- Bootstrap 5
